# بوابة الطالب

تطبيق Flutter تجريبي لنظام مصادقة طلابي، مبني ببنية MVC مع Repository Pattern، ومن دون حزم تشغيل خارجية.

## الشاشات

- تسجيل الدخول، مع التحقق من المعرف وكلمة المرور وخيار «تذكرني».
- إنشاء حساب مع التحقق من البيانات وكلمة المرور والموافقة على الشروط.
- استعادة كلمة المرور وإرسال رمز تحقق تجريبي.
- تعيين كلمة مرور جديدة مع التحقق من رمز OTP والتأكيد.

## البنية

- `lib/models/`: نماذج المستخدم وطلبات المصادقة.
- `lib/repositories/`: عقد المستودع وتنفيذه بمحاكاة شبكة وتخزين مؤقت.
- `lib/controllers/`: `AuthController` لإدارة الحالة.
- `lib/utils/`: مدققات النماذج.
- `lib/views/auth/`: واجهات المصادقة.

## الحساب والرمز التجريبيان

- المعرف: `202400001`
- البريد: `student@university.edu`
- كلمة المرور: `Student1`
- رمز الاستعادة: `123456`

المستودع يحاكي الشبكة ويخزن الحسابات في الذاكرة فقط؛ لذلك لا تبقى الحسابات بعد إغلاق التطبيق، ولا يتم إرسال رسائل بريد فعلية.
